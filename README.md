# CLUB69 OpenWorld Banners

Public delivery repository for the remote banner images used by the CLUB69 OpenWorld VRChat world.

The protected administration interface will be hosted separately. This repository contains public delivery assets only.

## Publishing rules

- Keep every filename stable. Replace file contents instead of renaming files.
- Recommended horizontal resolution: **1280 x 720**.
- Recommended vertical resolution: **720 x 1280**.
- Use optimized JPEG images in sRGB color space.
- Do not exceed VRChat's remote image limit of **2048 x 2048** pixels.
- Publish only final images intended to be visible to every visitor.
- Never commit passwords, API tokens, server configuration, private source files, or personal data.

## Files

- `banners/`: Stable files consumed by VRChat.
- `banner-manifest.json`: Slot metadata for the future Hetzner administration interface.
- `index.html`: Public preview and status page.
